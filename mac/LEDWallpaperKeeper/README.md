# LED 바탕화면 지킴이 (macOS 메뉴바 앱)

외부 디스플레이(LED 등)에 지금 나가고 있는 화면을 몇 초마다 캡처해서
**그 디스플레이 각각의 바탕화면**으로 지정합니다. 메인 모니터는 건드리지 않습니다.
PVP3 / ProPresenter가 튕기면 출력 창이 사라지고, 그 자리에 마지막으로 캡처한 화면이 바탕화면으로 보입니다.

## 받는 법 (빌드된 앱)
1. GitHub 저장소 → **Actions** → "Build LED Wallpaper Keeper (macOS)" → 최신 실행 → 아래 **Artifacts**의 `LEDWallpaperKeeper` 다운로드
2. 압축 풀고 `LEDWallpaperKeeper.app`을 **응용 프로그램** 폴더로 옮기기
3. 터미널에서 한 번 실행 (인터넷에서 받은 서명 없는 앱이라 막히는 것 해제):
   ```
   xattr -dr com.apple.quarantine /Applications/LEDWallpaperKeeper.app
   ```
4. 앱 실행 → **시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음**에서 LEDWallpaperKeeper 켜기 → 앱 종료 후 다시 실행

## 직접 빌드 (맥에서)
```
xcode-select --install        # 처음 한 번
cd mac/LEDWallpaperKeeper
./build_app.sh                # → dist/LEDWallpaperKeeper.app
```

## 메뉴 (상단 메뉴 막대의 사진 아이콘)
- **지금 캡처해서 바탕화면으로**: 수동 캡처 (⌘C)
- **적용할 외부 디스플레이**: 연결된 외부 디스플레이마다 체크로 켜고 끔 (기본: 전부 켜짐, 메인 모니터는 목록에 없음)
- **자동 캡처** / **캡처 간격** (3초~5분, 기본 5초)
- **PVP3/ProPresenter 켜져 있을 때만 자동 캡처** (기본 켜짐): 프로그램이 꺼지거나 튕기면 캡처를 멈춰서, 튕긴 뒤의 빈 화면이나 오류창이 바탕화면을 덮어쓰지 않음
- **로그인할 때 자동 실행**, **캡처 저장 폴더 열기**

## 꼭 알아둘 한계
- macOS 14(소노마) 이상 필요.
- 재생 프로그램이 **완전히 종료(튕김)** 되어 출력 창이 사라져야 바탕화면이 보입니다. 프로그램이 **멈춰서(응답 없음)** 창이 남아 있으면 그 멈춘 화면이 그대로 보입니다.
- 외부 디스플레이에 **메뉴 막대·Dock**이 보일 수 있습니다. 시스템 설정 → 제어 센터 → "메뉴 막대 자동으로 가리기: 항상", Dock 자동 가리기를 켜 두세요.
- **디스플레이 미러링** 중이면 macOS가 화면을 하나로 봐서 외부 디스플레이로 잡히지 않습니다. 확장 모드로 써야 합니다.
- 바탕화면은 그 디스플레이의 **현재 Space**에만 적용됩니다. Mission Control에서 Space를 여러 개 쓰면 공연 중엔 하나만 쓰세요.
- 캡처 순간에 전환 효과 중간 화면이 잡힐 수 있습니다 (간격이 짧을수록 튕긴 순간과 가까운 화면).
- 디스플레이 잠자기·화면 보호기는 꺼 두세요.
